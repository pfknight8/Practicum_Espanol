# Verbs that behave like 'Gustar'

These are verbs that are constructed in a "backwards" way: the subject and inderect objects are swapped from their usual order (at least when it comes to the English transaltios). As a result, they only have 3rd person conjugations, utilizing indirect object pronouns to indicate the person to which it applies.

For example, "Me gusta la piscina" = "I like the pool," or more literally "The pool is pleasing to me." Another example, to show plural objects, is "Me gustan los zapatos" = "I like the shoes," or more literally "The shoes are pleasing to me." Notice that the core verb is conjugated based on the 'object' of the sentence, in the first case a singular object, and a plural object in the second, despite the fact that both apply to the 1st person singulare "me" pronoun.

Notice, these verbs are not presented as 'reflexive,' even though the *always* are accompanied by indirect object pronouns. Since this applies to all verbs, it's worth remembering what these pronouns are here:
- Me = 1st person singular
- Te = 2nd person singular
- Le = 3rd person singular
- Nos = 1st person plural
- Os = 2nd person plural
- Les = 3rd person plural

## Flexibly Behave Like Gustar

These verbs can be conjugated normally, but also may behave like gustar, depending on the circumstance.

### **Caer bien (mal)**

- To (not) suit;
- In this case, "caer" is a normal verb, but in this specific phrasing, it is constructed like gustar.

### **Dar asco**

- To be loathsome
- In this case, "Dar" is a normal verb, but in this specific phrasing, it is constructed like gustar.

### **Parecer**

- To seem; to appear to be (something) to (person)
- Because other person(s) can be the object of this verb, it can be conjugated in more than the 3rd person.
- For example, "¿Te parecemos tontos?" = "Do we seem like fools to you?"

### **Molestar**

- To be a bother to
- in this case, this verb also can behave normally, so it depends on the circumstance.
- For examle, "A ella, le molesta que siempre llegue tarde" = "It bothers her that he is always late"
